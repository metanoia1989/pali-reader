叶环一眼

一片首尾收尖的叶子合拢成环，左腹比右腹多鼓 2 单位，所以它是有方向的、不是圆；环里只放一条线——弧线或杏仁，读到的是眼睛。四个候选共用同一套环几何与同一条眼线，只换环的画法，这样比的才是环。大样下面垫虚线是构造圆（过两个最宽点，r = 15.5）与叶轴。

1–2 · 四个候选，以及 48 / 32 / 16

1

描边环 · 弧线眼

羊皮纸 + 白底 · 48 / 32 / 16

16px：不行。环线只剩 1.05px，里面那根弧线缩到 3.3px 长——轮廓勉强站住，眼睛没了，读成一片空叶。

2

描边环 · 杏仁眼

羊皮纸 + 白底 · 48 / 32 / 16

16px：糊了。杏仁的内孔只有 0.9px，直接填实——16px 下它就是一片叶子加一道横杠，眼睛和瞳孔分不开。

3

实心笔环 · 弧线眼

羊皮纸 + 白底 · 48 / 32 / 16

16px：站得住。笔环比描边粗一档（1.4px），眼线与环内缘的缝只剩 0.4px 并合——退化成「叶＋一道横」，但字形有方向、不脏。

4

实心笔环 · 杏仁眼 · 断尖

羊皮纸 + 白底 · 48 / 32 / 16

16px：笔画没事，想法丢了。叶尖那道断口只剩 0.4px，读成一根毛刺而不是断口——断尖这个动作只能在大尺寸讲。

3 · 推荐

选 3 号，实心笔环 + 弧线眼。环做成 5.5 单位的实心笔带而不是细描边，缩到 16px 还剩 1.4px，是四个里唯一两头都读得出来的；而眼睛是环里唯一的负空间分隔线，不依赖任何细线，所以 512px 是「叶环里一只眯着的眼」，16px 是「叶＋一道横」，两端的说法一致，中间不会变形。

5 · 几何

叶轴从 (34, 4) 到 (31.8, 60)；右腹由控制点 (52.7, 24.8) 与 (52.1, 40.8) 给出 14.6 单位，左腹由 (10.7, 37.2) 与 (11.2, 25.1) 给出 16.5 单位——左边多鼓 2 单位就是这枚环不对称、不像圆的全部来源。笔带（外叶减内叶，evenodd）在 512px 上是 44px、在 32px 上是 2.75px、在 16px 上是 1.4px，同一比例 8.6%，全程不下细线；16px 以下不再变细，改由浏览器像素对齐。竖直方向没有上移：上下都是尖，重量相等，本来就不偏；只做了水平光学对中——叶轴是斜的，整枚环相对画布中心右移了 1 单位（约 1.5%）。
