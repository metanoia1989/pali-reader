旧稿的问题不在配色太少，而在四种浅底彼此只差两三个明度点：真正在分开四行的其实是四条 2px 规矩，而灰规与蓝规在 2px 上并没有「一眼」的差别；同时 #eef2f7 与 #cfdcec 是同一个蓝的两个明度，于是「词」和「参」成了亲戚——可它们本该离得最远。新方案按归属分三层底，行身份交给 20×20 的图表片去扛，全页只剩一条墨蓝竖规。另外「参」不再压灰：别人的字也要读得清，安静靠的是不铺底、缩进与发丝线。

参 他人译文

不铺底，靠 30px 缩进与上下发丝线成段，正文用 #3d3d3a 满对比。别人的字，安静来自结构与署名，不来自压低对比。

nom sg 教说

同一枚墨蓝的两种用法：语法走暖砂底 + 橄榄文字（无色相），义项走淡墨底 + 墨蓝文字。不加第二种彩色，靠底色的冷暖与文字的有无彩色分开。
